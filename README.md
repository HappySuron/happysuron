### 🎮 Games

| Project | Genre | Description |
|---------|-------|-------------|
| **SUAI_PK** *(frozen)* | RPG | Foundation for a story-driven isometric RPG inspired by *Disco Elysium*. Implemented: character movement (WASD / mouse click), branching dialogue system, inventory, modular architecture. |
